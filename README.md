## Проекты

### 1. A/A/B-тест изменения шрифта в мобильном приложении

**Задача:** оценить влияние нового шрифта на действия пользователей приложения по продаже продуктов питания.

Проверены и подготовлены данные эксперимента, проведено сравнение долей пользователей, совершивших основные события, включая успешную оплату. Дополнительно рассчитана событийная воронка в SQL и Python, исследованы сессии и пользовательские пути, создан интерактивный дашборд Tableau.

**Результат:** статистически значимых различий между группами по основным событиям не выявлено. В дополнительном исследовании установлено, что около 43% сессий содержат только главный экран; предложено проверить заметность перехода в каталог и порядок логирования событий.

**Инструменты:** Python, pandas, SQL (SQLite), Tableau.

### 2. Дизайн и анализ A/B-теста рекламной ленты Marketpele Feed

**Задача:** проверить, увеличивает ли изменение расположения рекламных элементов в ленте среднюю выручку на пользователя.

На исторических данных выбраны метрики и подготовлен дизайн эксперимента: распределение пользователей 50/50, плановая длительность — 4 недели. Рассчитан минимальный обнаруживаемый эффект (MDE), применены линеаризация CTR и CUPED. Отдельно проанализированы предоставленные результаты эксперимента.

**Результат:** статистически значимый рост выручки не подтверждён. По итогам анализа рекомендовано сохранить текущий вариант ленты и сформулированы направления дальнейшего исследования.

**Инструменты:** Python, pandas, Matplotlib, Seaborn.
