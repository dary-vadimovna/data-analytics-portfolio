## Проекты

### 1. Анализ поведения пользователей и результатов A/A/B-теста

**Цель исследования:** оценить поведение пользователей мобильного приложения и определить, повлияло ли изменение шрифта на доли пользователей, совершивших основные события, включая успешную оплату.

**Задачи:**

- Проверить качество и полноту данных.
- Определить период, пригодный для анализа.
- Построить воронку пользовательских событий.
- Изучить пользовательские пути и выделить сессии.
- Рассчитать воронку с помощью SQL.
- Провести A/A-тест между контрольными группами.
- Провести A/B-тесты и сравнить экспериментальную группу с контрольными группами.
- Сформулировать выводы и рекомендации.

**Основной вывод:** нет статистических оснований считать, что изменение шрифта повлияло на эти показатели, в том числе на долю пользователей с успешной оплатой.

**Инструменты:** Python, pandas, SQL (SQLite), Tableau.

### 2. A/B-тест изменения расположения рекламных элементов в Marketpele Feed

**Цель проекта:** проверить, приведёт ли изменение расположения платных и органических элементов к увеличению средней выручки на пользователя, и оценить изменения CTR Paid и количества просмотров страниц.

Проект состоит из двух блоков: дизайн теста и анализ полученных результатов.

**Дизайн теста:**

- Проверить типы данных и пропуски, обработать выбросы.
- Изучить распределения метрик, типы устройств, активность пользователей и конверсии.
- Сформулировать гипотезу, выбрать метрики, уровень значимости и мощность теста.
- Рассчитать MDE для нескольких вариантов длительности теста: 2, 3 и 4 недели.
- Провести A/A-тест для проверки ошибки первого рода и A/B-симуляцию для оценки мощности.
- Применить линеаризацию CTR Paid для статистического сравнения групп.
- Использовать CUPED для снижения дисперсии метрик.

**Анализ полученных результатов:**

- Ознакомиться с данными эксперимента.
- Проверить значимость различий метрик между группами.
- Сделать выводы и дать рекомендации бизнесу.

**Результат и рекомендация:** поскольку рост выручки на пользователя не подтверждён, а для CTR Paid статистически значимых различий не обнаружено, полученные результаты не дают оснований для внедрения нового варианта ленты. Рекомендуется сохранить текущую версию продукта.

**Инструменты:** Python, pandas, Matplotlib, Seaborn.
