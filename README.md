## Проекты

### 1. Анализ поведения пользователей и результатов A/A/B-теста

**Задача:** изучить поведение пользователей приложения и оценить влияние нового шрифта на доли пользователей, совершивших основные события, включая оплату. 
Проверены и подготовлены предоставленные данные A/A/B-эксперимента, проведено сравнение долей пользователей, совершивших основные события. Дополнительно рассчитана воронка событий в SQL и Python и создан интерактивный дашборд воронки в Tableau. Также исследованы сессии и пользовательские пути.

**Результат:** статистически значимых различий между группами по основным событиям, включая успешную оплату, не выявлено. В дополнительном исследовании установлено, что около 43% сессий содержат только главный экран; предложено проверить заметность перехода в каталог и уточнить особенности логирования событий.

**Инструменты:** Python, pandas, SQL (SQLite), Tableau.

### 2. A/B-тест изменения расположения рекламных элементов в Marketpele Feed

**Задача:** проверить, приведёт ли изменение расположения платных и органических элементов к увеличению средней выручки на пользователя.

На исторических данных выбраны метрики и подготовлен дизайн A/B-эксперимента. На предоставленных данных эксперимента проведена статистическая проверка различий между контрольной и тестовой группами.

**Результат:** гипотеза об увеличении средней выручки на пользователя не подтверждена. Полученные результаты не дали оснований рекомендовать внедрение нового расположения элементов; предложено сохранить текущую версию ленты.

**Инструменты:** Python, pandas, Matplotlib, Seaborn.
